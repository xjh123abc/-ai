## C1：45,200 元采购主流程

用 Playwright 和隔离 SQLite 测试账套，上传现有 45,200 元采购金标的采购发票、入库单和银行回单原件。财务人工确认结构化字段并完成人工关联后，后端真实调用 DeepSeek；provider 输入只含计划约定的白名单结构化字段和证据 ID，不含原始图像、银行账号或完整票据内容。

- AI 返回三条候选分录：借记库存商品 40,000.00、借记进项税额 5,200.00、贷记银行存款 45,200.00。
- Provider trace 为 `SUCCEEDED / PASSED`；账套科目、证据引用、会计政策及后端金额与借贷校验全部通过。模型、提示模板版本和候选摘要进入凭证 API 响应。
- 两个独立浏览器验收路径均通过：财务直接接受 V1；财务修正摘要后产生 V2，并由不同用户审批。
- 两条路径均导出 CSV，状态为 `EXPORTED_PENDING_MANUAL_POST`，界面和导出文件说明尚未写入 ERP。

## C2：失败与安全阻断

- API 回归验证 provider 超时后返回失败、写入生成失败审计且不保存草稿；未知科目、未关联来源引用、金额不符、借贷不平、关账、重复生成、缺失辅助核算及职责分离阻断均有覆盖。
- 新增 API 回归针对恶意候选分别注入未知科目、越权来源引用和错误金额，验证返回 422 且没有草稿落库。
- Playwright 超时和无效结构阻断回归验证界面显示明确失败原因、不显示凭证详情且不提供提交审核入口；两条失败 UI 路径使用确定性测试 provider 模拟。
- Provider 单元回归覆盖拒绝、限流、超时、连接失败、无效 JSON、结构无效及缺少配置等失败分支。
