# 凭证候选自主选科目

## Problem
费用政策要求预先固定借方和付款科目。制证时后端逐项比较模型分录与预设分录，模型无法依据报销事由和完整单据证据选择科目。

## Solution
财务负责人配置业务处理方式、税务处理和允许的有效末级科目范围。制证服务汇总业务组所有已确认单据的关键结构化字段，逐字段附单据引用，向 DeepSeek 提供现行科目表和政策。DeepSeek 识别业务性质、选科目、生成完整候选并解释每条分录及证据。后端仍核验金额、借贷平衡、科目有效性、政策范围、税务处理和关联证据；人工修正使用相同边界。

## Decisions
- 继续使用现有会计政策 JSON 和版本机制，修改配置契约，不加数据库迁移。
- 每份凭证草稿绑定生成时的政策版本，政策一旦更新，旧草稿就不能沿用。保存新政策时删除同业务类型下尚未提交审核的旧草稿及其分录，并留下审计记录；审核、导出及入账流程中的凭证阻止政策变更。旧业务重新核对后可按新政策制证。
- 允许科目使用已启用的末级科目代码列表；财务政策另标出进项税科目范围。可抵扣时该范围包含在允许科目中，不可抵扣时与允许科目分离；后端核对税额及禁止使用情况。
- 汇总字段仅来自业务组已确认版本的结构化提取，不传识别全文或银行账号。
- 模型提出候选，后端决定其是否可以成为草稿。

## Testing decisions
- 通过政策 API 验证保存、无效科目拒绝和政策版本。
- 通过业务组制证 API 注入模拟 DeepSeek，观察关联单据字段引用、可选科目成功制证及金额、税务、证据拒绝。
- 通过页面真实 API 模式验证政策编辑与凭证展示；静态演示不计入。

## Out of scope
真实 DeepSeek 调用、ERP 入账、改变租赁逐笔确认规则。
