# 02: 单据 OCR 信息按三层展示

**What to build:** 财务人员在单据审核页先看到记账关键字段，按需展开完整展示的业务辅助字段，布局与关键字段一致，并按需查看完整 OCR 原文；关键字段保存时仍需人工确认。

**Blocked by:** None

**Status:** Implemented; browser E2E unverified because Chromium cannot start without `libnspr4.so`.

- [x] 有明确候选的关键字段自动预填并标记待确认；无明确候选或歧义字段不自动填值。
- [x] 银行账号、开户银行、电子回单号、交易流水号等辅助字段提取并完整保留，默认折叠；账号显示完整值。
- [x] 保存关键字段确认版本时，不丢弃未编辑的辅助字段。
- [x] OCR 完整原文（含银行说明、表头和备注）继续完整保留，按需展开查看，不转换为会计字段。
- [x] API 回归覆盖信息分层数据保留；浏览器验收已写，运行受环境阻塞。
