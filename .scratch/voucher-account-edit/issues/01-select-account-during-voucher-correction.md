# 01: 修正凭证时改选会计科目

**What to build:** 修正凭证时可手动输入科目名称，也可从当前账套可用末级科目中选择并同步编码；保存后生成新版本并重新校验。

**Blocked by:** None

**Status:** ready-for-agent

- [ ] 修正模式下，可手动输入分录科目名称。
- [ ] 修正模式下，可从当前账套可用末级科目中选择科目，选择后编码与名称同步更新。
- [ ] 保存后保留用户手输的科目名称；科目编码仍须为当前账套可用科目。
- [ ] 保存后新版本保留所选科目，旧版本保持不变。
- [ ] 后端仍执行账套科目、末级科目、辅助核算及现有凭证校验。
