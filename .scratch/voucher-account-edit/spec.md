### Problem

AI 生成的凭证可能选择错会计科目。目前修正凭证时可以手改科目编码，但名称不能改，也不能从账套科目中选择来同步更正。

### Solution

修正凭证时，每条分录的科目名称可以手动输入，也可以从当前账套科目中选择。选择账套科目时，科目名称与编码一起更新。手动输入名称时，保存输入值；科目编码仍可手动修改。保存时后端校验编码属于当前账套可用的末级科目，并创建新凭证版本；原凭证版本保留。

### User stories

- 作为财务人员，我可以手动更正 AI 生成的科目名称和编码，也可以选择账套科目并自动同步编码与名称。

### Decisions

- 账套科目选择器只提供当前账套有效的末级科目；选择条目时由账套数据提供名称与编码。
- 用户手动输入的科目名称保存在凭证分录上；科目编码仍须通过当前账套和现有会计政策校验。
- 分录修正仍通过现有凭证新版本流程保存，不改写旧版本。

### Testing decisions

- 通过凭证修正界面手输科目名称或选择账套科目，观察名称、编码的变化；保存后确认新版本保留手输名称或所选科目，旧版本不变。
- 通过现有凭证修正 API 验收手输名称的保存、新版本和后端编码校验。该验收不代表 ERP 已入账。

### Out of scope

- 凭证中新增或删除分录。
- 修改账套科目表或会计政策。
- 手工输入账套科目表中不存在的科目编码。
- ERP 写入与回读。
